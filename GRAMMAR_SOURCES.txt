C++ grammar candidates for the ambiguity project
Retrieved/verified: 2026-10-02

These are the two historical candidate grammars discussed in this chat.
Neither has been confirmed as the exact C++ grammar used in the NSF final
report. They are original Yacc sources, not converted inputs for grammar_engine.py.
All downloaded/extracted source files are preserved byte-for-byte.

1. cfront/gram.y

   Cfront release 3.0.3 (the archive dates this release May 1994).
   The source header identifies the C++ Language System, Release 3.0.
   Source file:
   https://softwarepreservation.computerhistory.org/c_plus_plus/cfront/release_3.0.3/source/src/gram.y
   Archive context:
   https://softwarepreservation.computerhistory.org/c_plus_plus/

   This is the compiler's syntax analyzer, including C++ semantic actions,
   precedence declarations, and syntax extensions for error handling.
   It depends on the rest of cfront; this single file is not a standalone
   compiler. Removing actions or directives would require a separate,
   documented conversion before treating it as a pure CFG benchmark.

   The archive states that the cfront sources are posted with permission
   of the copyright owner for historical research purposes only.
   The original copyright/proprietary notices are retained in gram.y.
   For that reason gram.y and its conversions are not distributed in this
   repository; README.md explains how to fetch, verify and convert it.

2. roskind/cpp5.y

   Jim Roskind's grammar release 2.0, July 4, 1991.
   Companion grammar5.txt is updated July 11, 1991 and describes a C++ 2.1
   grammar. The grammar release number is distinct from the C++ version.
   Source archive (original Roskind files preserved by Robert Elder):
   https://blog.robertelder.org/jim-roskind-grammar/c%2B%2Bgrammar2.0.tar.Z
   Mirror context and published archive checksum:
   https://blog.robertelder.org/jim-roskind-grammar/
   Archive SHA-256:
   9cb8bf51f9b54b998e2058bec9892f170985e303a24c6d774ed186ec49ee065b

   Included unchanged from the archive:
   cpp5.y       - C++ grammar, start symbol translation_unit
   cpp5.l       - accompanying demonstration lexer
   freegrm5.txt  - introduction, limitations, and historical build instructions
   grammar5.txt - ambiguity discussion and conflict analysis
   autodoc5.txt - guide to the generated analysis
   y.output     - original generated grammar/parser analysis

   This release omits templates and exception handling. The demonstration
   lexer lacks preprocessing, comment removal, and a symbol table; it
   guesses that uppercase-leading names are type names. These limitations
   are documented in freegrm5.txt. The grammar has no precedence or
   associativity declarations to resolve conflicts.

   The notices and copying terms are retained in the original files.
   y.output is historical upstream output, not a fresh local parser run.

Verification

The Roskind archive matches its published SHA-256 checksum. Each copied
file was compared byte-for-byte with its downloaded file or archive member.
Both grammar files were checked for Yacc declarations and grammar sections.
No grammar conversion or parser build was performed.
